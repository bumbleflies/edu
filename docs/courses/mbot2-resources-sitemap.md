## 10. Guide Structure Overview

The After-school Program Guide follows this learning path:

```
Lessons (9)
├── Lesson 1: Let's move — Precise movements & coding blocks
├── Lesson 2: Sensing = data — Sensors, data visualization, Live vs Upload mode
├── Lesson 3: Listen to mBot2 — Sound sensor, speech recognition
├── Lesson 4: Seeing with sound — Ultrasonic sensor applications
├── Lesson 5: Sightseeing — Camera/sensor-based navigation
├── Lesson 6: Careful drive — Motor precision
├── Lesson 7: A network game — WiFi/multi-robot communication
├── Lesson 8: mBot2 at your service — Cloud services, own blocks (functions)
└── Lesson 9: mBot2 in the wild — Machine Learning, custom protocols

Challenges (3)
├── Challenge 1: Monitoring vertical crops — Distance keeping, color detection
├── Challenge 2: Transporting goods around the farm — Location identification, transport
└── Challenge 3: Processing waste — Smart Logistics competition

Smart World Add-on Activities
├── Robotic Carrier (Bluetooth Controller)
├── Surveying Robot (Bluetooth Controller)
└── Robotic Arm (Bluetooth Controller)

Competition: Smart Logistics Arena
```
